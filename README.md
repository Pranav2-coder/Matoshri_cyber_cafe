# Matoshri Cyber Cafe 🌐

A modern, fast, and responsive web portal for **Matoshri Cyber Cafe** — providing local assistance with government document applications, certificates, and online citizen services in Nagpur, Maharashtra.

---

## 🚀 Features

- **Service Directory & Search**: Instant real-time filtering and search across government certificates, identity cards, licenses, and utility services.
- **Service Categories**:
  - Government & Revenue Certificates (Caste, Income, Domicile, Non-Creamy Layer)
  - Identity & Registration (Aadhaar assistance, PAN Card, Voter ID, Ration Card)
  - Travel & Transport (Passport assistance, Driving License, RTO online services)
  - Banking & Digital Services (AEPS, Bill Payments, Online Applications)
- **Direct WhatsApp Consultation**: One-click WhatsApp connect with pre-filled service inquiry messages.
- **Modern Responsive Design**: Fluid mobile drawer navigation, branded preloader, dynamic interactive service cards, and SEO-optimized metadata.
- **Official Branding**: Custom typography, brand color scheme (Saffron & Deep Navy), and logo integration across navigation, preloader, and tab icon.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS Design System with CSS variables and responsive grid

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Pranav2-coder/Matoshri_cyber_cafe.git
   cd Matoshri_cyber_cafe
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
